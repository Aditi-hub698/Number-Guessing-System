# Number Guessing Game (C++)

## Description

This is a simple console-based Number Guessing Game developed in C++.

The user has to guess a secret number. The program provides hints if the guess is too high or too low until the correct number is guessed.

## Features

- User Input
- while Loop
- if-else Statements
- Attempt Counter
- Console-based Game

## Concepts Used

- Variables
- Input/Output
- while Loop
- if-else
- Comparison Operators
